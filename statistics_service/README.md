# Statistics Service

## Зона ответственности
- Подсчет статистики по постам: количество лайков, просмотров и комментариев.
- Обеспечение актуальных данных для аналитики.

## Границы сервиса
- Входные данные: события, связанные с лайками, просмотрами и комментариями, передаются через брокер сообщений.
- Выходные данные: статистические данные, предоставляемые через API Gateway по запросу.
- Используемые компоненты:
  - ClickHouse для хранения и обработки статистических данных.
  - Apache Kafka для получения событий о действиях пользователей в системе (просмотры, лайки, комментарии).
