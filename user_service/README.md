# User Service

## Зона ответственности
- Регистрация и аутентификация пользователей.
- Хранение информации о пользователях, сессиях и отношениями между пользователями (заблокирован, добавлен в друзья).
- Управление пользовательскими учетными записями.

## Границы сервиса
- Входные данные: запросы от API Gateway по управлению пользователями (регистрация, аутентификация и т.д.).
- Выходные данные: результаты аутентификации, данные пользователей.
- Используемые компонента: база данных PostgreSQL для хранения всей пользовательской информации.
