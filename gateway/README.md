# API Gateway

## Зона ответственности
- Прием всех входящих запросов от пользовательского интерфейса.
- Передача запросов соответствующим внутренним сервисам.
- Обеспечение REST API для внешних взаимодействий.

## Границы сервиса
- Входные данные: запросы от UI (создание/удаление/обновление постов, регистрация и авторизация пользователей и т.д.).
- Выходные данные: ответы от других сервисов, передаваемые обратно в UI.
- Используемые компоненты: API Gateway имеет взаимодействие с каждым из трех внутренних сервисов.
