# Posts and Comments Service

## Зона ответственности
- Создание, обновление и удаление постов.
- Управление комментариями к постам, включая ответы на комментарии.
- Обеспечение механизма взаимодействия с содержимым постов.

## Границы сервиса
- Входные данные: запросы от API Gateway на управление постами и комментариями.
- Выходные данные: данные о постах и комментариях по запросу.
- Используемые компоненты:
  - База данных PostgreSQL или Cassandra для хранения постов и комментариев.
  - Apache Kafka для отправки событий о новых постах, комментариях, лайках и просмотрах.
